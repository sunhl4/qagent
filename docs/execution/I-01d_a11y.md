## 产品锁

- `#stage` 仍由 `setBusy()` 写 `aria-busy` true/false。忙时 `#composer` 和 `#send` 同样标 busy，读屏知道主面和发送条都在等。
- 发送只走两处：`#composer` submit，以及 `#prompt` 自己的 keydown。Enter 发送、Shift+Enter 换行。IME 组合中 `ev.isComposing` 直接 return，不发送。
- 没有 document / window 级 keydown。输入中快捷键不抢：焦点在 input / textarea / select（设置里的密码、知识库路径、模型字段）时，全局键不能抢发送。设置开着时 Enter 也不走聊天。
- 设置表是 `method=dialog`，和 composer 不是一张表。设置字段里的 Enter 只提交对话框，不冒泡成聊天发送。
- 3080 仍是对话主面。不加 Finder 工作区，不加三房间。
