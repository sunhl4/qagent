# 原生 DSH 三栏展示

更新：2026-10-21

页面已改为同一套三栏布局。DSH 的真实工作空间、会话列表和设置入口放在左栏；右栏只渲染原生对话。消息、输入框、模型选择、上下文、工具和审批组件不改动，也不在右栏嵌套第二套侧栏。

## 打开展示

首次准备：设置 `COMPANY_AGENT_DSH_HOME=$HOME/.cache/unitqc-company-agent/dsh-demo-home` 后运行 `bash scripts/bootstrap_dsh.sh`。

启动：`python3 scripts/serve_workspace_demo.py`。打开程序打印的本机启动链接，完成 DSH 认证后进入 `http://127.0.0.1:3081/`。

启动入口默认使用 `17867`，DSH 使用 `3081`，均只监听本机。`8767` 曾与 Windows 的 Cursor 转发冲突，已不作为默认端口。启动链接包含访问凭据，不宜公开分享；换浏览器或启动进程后使用本次打印的完整链接。Ctrl+C 停止展示及其启动的 DSH。

## 三栏操作

- 左栏：云平台、超算、本机示例目录；下方是 DSH 原生的真实工作空间和会话列表。新建、搜索、选择会话继续由 DSH 处理。
- 左下角：账号入口、原生 DSH 设置、平台连接设置。账号及云 / HPC 连接仍未接入；DSH 设置是真实原生界面。
- 中栏：文件、报告、Canvas 和平台连接页面，保留之前的内容样式。
- 右栏：原生对话。点击左侧真实会话会切换这里，打开中栏文件不会切换会话。
- 顶部“左栏 / 中栏 / 对话”分别收起和恢复面板，至少保留一栏。
- 拖动两条分隔线调整宽度；选中分隔线后也可用左右方向键调整，双击或 Home 恢复该侧默认宽度。“重置布局”恢复三栏。
- 宽度与显示偏好保存在当前浏览器；隐藏面板保留组件，不清空未发送草稿。窄屏以“目录 / 内容 / 对话”切换整个区域。

## 如何复用 DSH

项目使用 DSH CLI `0.1.5-rc.2`，前端按现有锁文件为 `0.1.5-rc.3`；没有升级依赖锁或改写已安装的上游文件。

新增 `apps/company-workspace/` 仅负责展示层组合：利用固定版本的 boot manifest 和 Slot 接口替换外层布局与侧栏容器，直接渲染原生 `main/conversation`、`sidebar.workspaces`、`sidebar.settings` 与覆盖层。它不实现模型、消息、会话或工具循环，不注册业务工具。公司内容页单独放入 iframe，样式不会污染原生对话。

此组合依赖固定版本的内部前端接口，升级 DSH 时必须重新验证；不是宣称上游已有稳定的嵌入协议。`http://127.0.0.1:3081/?native=1`（已认证后）保留完整上游布局用于对照。

展示叠加只在 `development + company-agent-minimal + boot` 下启用。生产 profile、科学合同、设备策略与 Codex 隔离保持不变。

## 当前范围

- 真正可操作：DSH 原生工作空间 / 会话导航、原生输入区与设置、三栏显隐和拖动。
- 仍是示例或未接入：本机示例文件、公司用户注册、云 / HPC 账号、知识读写及开发服务。
- 模型 API key 没有配置。本次测试只在输入框填入再清除草稿，没有发送消息、调用科学服务或设备。
- 单独的 `DSH_HOME` 不继承模型或科学服务凭据，但之后手动保存的配置会保留。该环境是可信本机展示，不是多租户沙箱，不能直接对外暴露。
