# D2 册更新：上下文、知识与恢复

详见 [逐项目复核索引](reviewed/README.zh-CN.md)：07 Aider、11 Letta、34 Mem0、35 Graphiti、36 Cognee、37 LangGraph、38 LLMLingua、39 Repomix。当前版本、迁移关系及许可证分别以逐项证据为准，不从附属仓偷换研究对象。

## 复核后的边界

- Checkpoint 重建会话状态，不证明外部作业 exactly-once；pending writes 也不是云平台受理回执。
- Git 历史能保存版本，不自动提供数据时效、租户授权或合规审计。记忆来源、有效期、撤回和访问控制仍需显式设计。
- 提取实体、自动总结和压缩可能丢失安全上下文或扩大信息可见范围；内外部知识权限不能在摘要后失效。
- 内部源码打包成 Skill 之前也要授权；不把算法清单固化进知识库或技能。
- 大产物经平台授权资产管理，复用现有句柄类型，不创建通用“新 ID”逃离合同。

旧稿把记忆存储等同业务恢复、把分层记忆样本当作公司可直接接入组件的结论均需以上述边界重读。建议见 [工程衔接](04-工程衔接建议.zh-CN.md)。
