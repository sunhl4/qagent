## 按当前页面实现

**v0.5 渲染结果只约束左栏、中栏和外围布局。右栏完全以 DeepSeek Harness 原生对话界面为准，不采用本原型的自绘样式。** 服务接入不重做左栏和中栏，也不改造 DSH 的内部界面。

- 延续现有浅色背景、灰色分隔线和少量青色强调，不增加横幅、渐变或宣传卡片。
- 工作区占满窗口。架构导航、版本介绍和说明文档通过右上角“设计文档”进入，不出现在操作页面中。
- 原生接入后右栏加宽：常规桌面左栏 220 px，右栏为窗口宽度的 42%（限制在 480–720 px），中栏填充剩余空间；901–1150 px 下左栏 185 px、右栏 440 px。可用“展开对话”临时让 DSH 占满左栏以外的区域；只改变容器，不裁剪或改动原生控件。
- 左栏顺序固定：云平台、超算、本机文件、工作空间。前两项默认折叠，账户和齿轮固定在左下角。目录区域独立滚动。
- 中栏采用标签页。标签只显示名称，路径放在下方；同名文件用来源路径区分。打开内容不切换对话，关闭标签不删除文件。
- 首页只保留资源入口和项目文件。文件、报告和设置在同一内容区打开。
- 设置保留账号、云平台、超算、模型、知识与开发；以字段和连接状态呈现，不写产品介绍。
- 641–900 px 下目录在左，内容与对话在右侧上下排列；640 px 及以下使用“目录 / 内容 / 对话”切换，避免把整页堆成很长的一列。

### 右栏必须原样使用 DSH

2026-10-21 已接入项目锁定版本的完整原生网页，使用独立来源 iframe 隔离 CSS 和 DOM；自画标题、模型栏和占位内容均已移除。启动与展示方式见 [原生 DSH 展示版](native-dsh-demo.zh-CN.md)。

- 直接复用固定版本 DSH 的完整对话区域，包括标题 / 工具栏、消息、输入框、模型选择、上下文用量、工具记录、审批、快捷键和状态反馈。
- 不重绘、精简、改文案、重排、裁剪或隐藏原生控件；不向原生界面注入自定义 CSS，也不让宿主的字体、主题或全局选择器污染它。接入时须验证样式与事件隔离。
- 左下角设置只提供打开 DSH 原生设置的入口；不另造模型表单，也不移动或删除对话中已有的设置入口。
- 左栏只通过已验证的接口选择会话；外围页面不代画会话标题、消息或执行状态。
- 允许调整外层容器位置和大小，原生内部布局与交互保持不变。窄屏时切换整个区域，而不是简化原生界面。

本机展示已验证原生输入区、模型设置、独立样式和展开恢复；没有修改上游文件。当前使用 DSH 原生侧栏管理真实会话，左侧示例会话禁用，尚未实现双方会话联动。多用户部署、真实模型调用与科学服务仍需单独验收。

## 文案规则

- 名称直接写用途：“项目知识”“代码变更”“知识草稿”。不用“可信内容工作区”“边开发边形成知识候选”等标题。
- 普通空状态只写当前情况和下一步。例如“知识库未连接”“连接后搜索项目资料”。
- 按钮写动作：“连接设置”“保存草稿”“打开页面”。没有实现的动作禁用，不做假的成功提示。
- 连接状态只在相关位置显示。预览身份统一标在顶栏；图表另保留“示例数据 / 非计算结果”，避免被当成真实结果。
- 普通页面不解释运行时、工具合同或权限设计。涉及真实提交、删除、费用和设备执行时，完整保留必要的确认与风险信息。
- 登录、模型、知识和开发服务未接入时明确显示“未连接”，不显示虚构账户、模型名称、上下文用量或测试成功记录。

## 验收办法

1. 对照本页渲染检查首页、文件、设置、报告和未连接状态，不能把说明文档重新放进操作区。
2. 在 1440、1024、768、390 px 宽度下检查滚动、入口可见性、文字截断及布局；同尺寸截图用于后续视觉回归。
3. 检查标签去重、来源路径、会话保持、手机面板切换、账户弹窗、配置校验和设计文档往返。
4. 界面测试与业务验收分别记录。真实身份、DSH 原生对话、文件授权、知识服务和设备不能只靠截图判定完成。

原型交互测试：`npm test --prefix tests/ui`。测试检查短文案和无副作用状态，防止以后重新堆入说明文字。

浏览器检查：设置 `COMPANY_UI_PLAYWRIGHT` 为已安装 Playwright 的 `index.mjs` 绝对路径，执行 `npm run test:browser --prefix tests/ui`。可用 `COMPANY_UI_SCREENSHOTS` 指定截图目录；浏览器依赖不装入 DSH Runtime。

本次 13 项交互测试和 Chromium 检查通过，检查宽度为 1440 / 1024 / 900 / 850 / 768 / 641 / 640 / 390 px。已查看首页、设置和手机截图；截图暂存于本机临时目录，仓库中的页面、样式与测试是可复现基准。本轮未运行完整 Python 回归或真实服务验收。
