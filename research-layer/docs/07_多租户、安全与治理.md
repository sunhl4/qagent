# 多租户、安全与治理

## 1. 目标

让同一套 DSH 平台安全地服务多个用户、团队和项目，同时保证：

- 数据隔离
- 权限最小化
- 成本可控
- 动作可审计
- 高风险操作可阻断
- 事故可恢复

## 2. 身份体系

| 主体 | 认证 | 授权 |
|---|---|---|
| 人类用户 | 企业 OIDC + MFA | RBAC + ABAC |
| 服务 | 工作负载身份 + mTLS | 最小权限 + 短期 |
| Agent | 独立主体 | 不继承用户全部权限 |
| 运维 | 独立 IdP + 强 MFA | JIT + 双人审批 |
| 外部供应商 | 签名 + 白名单 | 仅限接口范围 |

### 2.1 Agent 身份

Agent 必须是独立主体，不能复用用户 token。原因：

- Agent 行为不等同于用户行为。
- 需要独立审计。
- 需要独立配额。
- 需要独立撤销。

### 2.2 权限模型

```text
主体
  × 租户
  × 项目
  × 资源类型
  × 动作
  × 数据分类
  × 时间窗口
  × 预算
  → 允许 / 拒绝 / 需审批
```

## 3. 租户隔离

| 级别 | 隔离方式 | 适用 |
|---|---|---|
| 软隔离 | namespace + RBAC + 配额 | 内部可信团队 |
| 硬隔离 | 独立集群/节点池 + 独立存储 | 外部或互不信任 |
| 专属 | 独立数据库 + 专属资源 | 高敏或合规 |

硬规则：

- namespace 不是硬安全边界。
- 高敏租户不得与他人共享节点。
- 每租户独立加密密钥。
- 每租户独立审计视图。

## 4. 沙箱

### 4.1 要求

- 非特权容器或微虚机。
- 只读根文件系统。
- 临时目录配额。
- 默认拒绝出网。
- 禁止宿主 socket。
- 禁止访问云元数据。
- CPU/内存/进程/磁盘限制。
- 硬超时。
- 独立工作区。

### 4.2 分级

| 级别 | 技术 | 场景 |
|---|---|---|
| S0 | 进程 + 只读 | 只读分析 |
| S1 | Docker 非特权 | 一般代码 |
| S2 | gVisor / Kata | 不可信代码 |
| S3 | 独立节点 + 无外网 | 敏感数据 |
| S4 | 硬件隔离 | 真实设备 |

### 4.3 出网

- 默认无网络。
- 白名单按域名与端口。
- 通过代理审计。
- 禁止任意 DNS。
- 禁止访问内网管理面。

## 5. 凭据管理

### 5.1 禁止

- 长期密钥写入提示词。
- 长期密钥写入脚本或环境变量。
- 长期密钥写入镜像。
- 长期密钥放在共享目录。
- 在日志中输出 token。

### 5.2 推荐

```text
任务启动
  → 工作负载身份认证
  → 凭据代理签发短期 token
  → token 绑定租户/项目/资源/动作/时长
  → 通过本地 socket 或受限文件注入
  → 任务结束撤销
```

### 5.3 轮换

- 自动轮换。
- 撤销传播纳入 SLO。
- 泄露演练。

### 5.4 资源租约

资源租约是短期能力凭证，不是长期密钥：

- 只有 `ACTIVE` 且在时间窗口内的租约可以执行任务。
- 续租提升 fencing token，旧 token 永久失效，防止旧 worker 继续写。
- 租约过期立即拒绝新工作；释放幂等，释放失败进入 `DRAINING` 并保留预算预留。
- 执行状态未知时禁止释放结算和自动重试，必须先人工对账。
- 未知执行也禁止自动从检查点恢复；恢复前必须确认上一轮已终止。
- 恢复只使用同实验、同 attempt 且代码/环境一致的检查点；新 attempt 使用新产物前缀。
- 准入按悲观上界预留成本；释放确认后才结算实际成本并退回未使用预留。
- 实现位置：`packages/domain/src/lease.ts`、`packages/pipeline/src/lease.ts`、`packages/domain/src/cost.ts`、`packages/domain/src/checkpoint.ts`。

### 5.5 Super-agent 的端侧与 Watchdog

按五模块全部开源来规划时，仍然遵守：

- 端侧 daemon 不保存会话，不持有长期密钥。命令所需凭据由凭据代理签发短期令牌。
- Watchdog 只报告无进展和方向偏离。它不能修改策略、预算、租约，也不能在执行状态未知时重试。
- 群聊或 Issue 中的不可信文本是 Trigger 内容，不是系统指令。投机执行可以准备结果，高风险交付仍走第 6 节策略网关。
- 生产执行环境使用本工程的沙箱分级，不采用「以操作系统用户免审批执行」。

## 6. 策略网关

### 6.1 检查顺序

```text
1. 身份与租户
2. 项目与角色
3. 资源类型与配额
4. 预算
5. 数据地域与出口
6. 风险等级
7. 时间窗口
8. 审批状态
9. 依赖健康
```

### 6.2 决策

| 决策 | 行为 |
|---|---|
| ALLOW | 执行 |
| DENY | 拒绝并记录 |
| REQUIRE_APPROVAL | 创建审批请求 |
| ALLOW_WITH_LIMIT | 限制参数后执行 |
| DEFER | 等待资源或时间窗口 |

### 6.3 落法

- 优先使用 DSH 工具前置事件的 waterfall。
- 若事件粒度不足，使用平台工具代理。
- 所有决策写审计。
- 拒绝必须给出可解释原因。

## 7. 审批

### 7.1 审批矩阵

| 动作 | 级别 |
|---|---|
| 读公开文献 | 自动 |
| 解析文档 | 自动 |
| 创建分支 | 自动 |
| 修改实验分支 | 自动 |
| 单测 | 自动 |
| 预算内 CPU/GPU | 自动 |
| 超阈值 GPU | 审批 |
| HPC 长任务 | 审批 |
| 真实设备 | 审批 + 双人 |
| 外发专有数据 | 审批 |
| 生产变更 | 审批 |
| 合并主分支 | 审批 |
| 公开发布 | 审批 |
| 修改安全策略 | 审批 + 双人 |
| 硬件控制 | 禁止 |

### 7.2 审批记录

- 谁批
- 何时
- 批了什么范围
- 有效期
- 附带条件
- 撤销记录

## 8. 审计

### 8.1 必须记录

- 登录与 token 签发
- 策略决定
- 任务创建与状态变更
- 工具调用摘要
- 模型调用摘要
- 资源申请与释放
- 产物上传与下载
- 审批
- 管理员操作
- 失败与补偿

策略决定留痕的实现：每次策略评估经 `buildPolicyDecisionRecord()` 产出 `PolicyDecisionRecord` 并写 `policy-decision.json` 产物（操作者、动作目标、匹配规则、限额、审批人为空列表等待回填），拒绝与需要审批的路径同样留痕。记录不含提示词或凭据字段。

### 8.2 存储

- 追加写。
- 哈希链或签名。
- 不可篡改存储。
- 保留期按合规。
- 可按 trace 关联。

### 8.3 脱敏

- 不记录完整提示。
- 不记录 token。
- 不记录用户敏感数据。
- 需要时记录哈希与摘要。

## 9. 供应链安全

- 镜像按 digest 固定。
- 签名验证。
- SBOM。
- 漏洞扫描。
- 依赖锁定。
- 构建可复现。
- 第三方插件审查。
- 插件权限声明。

## 10. 数据治理

| 分类 | 示例 | 处理 |
|---|---|---|
| 公开 | 论文、公开代码 | 可用于外部模型 |
| 内部 | 内部文档、代码 | 仅内部模型或合规 API |
| 机密 | 客户数据、未发表结果 | 仅自部署或专用环境 |
| 受限 | 个人信息、受监管数据 | 最小化、加密、审计 |

规则：

- 数据分类决定可用模型与存储地域。
- 跨境传输必须审批。
- 删除请求必须可执行。
- 备份与保留策略明确。

## 11. 事故响应

### 11.1 场景

- 密钥泄露
- 越权访问
- 恶意代码执行
- 资源滥用
- 数据外泄
- 模型输出有害内容
- 供应链投毒

### 11.2 流程

```text
发现
→ 隔离（撤销 token、停任务、封禁插件）
→ 取证（日志、镜像、产物）
→ 影响评估
→ 修复
→ 恢复
→ 复盘
→ 规则更新
```

### 11.3 演练

- 每季度一次。
- 覆盖密钥泄露、沙箱逃逸、越权、资源滥用。
- 记录恢复时间。

## 13. 反模式

1. 用 namespace 当作唯一隔离。
2. Agent 复用用户 token。
3. 长期密钥放环境变量。
4. 只记录成功操作。
5. 审批没有范围与有效期。
6. 沙箱允许出网。
7. 插件不声明权限。
8. 模型输出直接执行。
9. 审计日志可修改。
10. 没有事故演练。
11. 让 Watchdog 或投机执行绕过策略网关。
12. 把端侧机器上的长期密钥交给云端 Agent 上下文。
