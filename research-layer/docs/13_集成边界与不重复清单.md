# 集成边界与不重复清单

## 1. 目的

本文件明确**研究层不做什么**，避免和仓库根目录的执行面重复。产品顺序见仓库根目录 `docs/super-dsh-product-plan.zh-CN.md`。

## 2. 根目录已经承担的能力

根目录代码已经在同一仓库。下表是研究层如何使用这些能力；真实联调仍要等 Owner 确认接口语义。

| 能力 | 根目录对外形态 | 研究层如何使用 |
|---|---|---|
| DSH 运行时 | 可启动的 DSH 服务/进程 | 通过 SDK 或 HTTP 驱动会话 |
| 云平台接入 | 提交、状态、取消、产物、计费 | `ComputePort` |
| 本地 HPC 接入 | 提交、队列、状态、日志、取消 | `HpcSchedulerPort` |
| 本地模型服务 | OpenAI 兼容或自有 API | `ModelGatewayPort` |
| 对象存储 | 上传、下载、签名 URL | `ArtifactStorePort` |
| 身份认证 | token 校验、主体解析 | `IdentityPort` |
| 短期凭据 | 签发、撤销 | `SecretPort` |
| 事件 | 发布、订阅 | `EventPort` |

## 3. 本工程明确不做

### 3.1 不重做 Harness

- 不 fork DSH。
- 不复制 Cordis。
- 不重写 Agent loop。
- 不重写工具调用协议。
- 不重写模型适配器。

原因：仓库根目录已经拥有 DSH 运行时和公司工具，研究层只消费，不另起一套。

### 3.2 不重做资源适配器

- 不写云厂商 SDK 封装。
- 不写 Slurm 客户端。
- 不写 HPC 队列管理。
- 不写 GPU 供应逻辑。
- 不写推理引擎部署。

本工程只定义端口、做能力协商、做预算与对账、做上层编排。

### 3.3 不重做身份与密钥

- 不建第二套用户表。
- 不建第二套租户表。
- 不建第二套密钥库。
- 不签发长期凭据。

本工程只做租户视图、项目视图、权限策略和审计。

### 3.4 不重做基础可观测

- 不自建日志系统。
- 不自建指标系统。
- 不自建 trace 后端。

本工程只产生结构化事件与 span，发到统一 OTel。

### 3.5 不重做 DSH 已有插件

如果对方已实现文件、终端、Git、基础检索等插件，本工程不重复实现，只在其上增加领域插件。

### 3.6 不重做 Super-agent

编码协作运行时按计划由上游开源，本工程不复制：

- Router 与 Worker
- Trigger、Thread、Ticket、Mandate、订阅直通
- Inline & Spill、链式召回
- 计算、状态与执行环境分离
- Watchdog

本工程只提供领域事件（实验完成、租约状态、预算耗尽）和合并门禁。见 `docs/15_Super-agent接入与两套时钟.md`。

## 5. 边界判定规则

遇到一个新需求，用四问判断归属：

```text
1. 它是不是“把外部资源变成可调用能力”？
   是 → 对方工程
   否 → 下一问

2. 它是不是“认证、密钥、基础存储、基础遥测”？
   是 → 对方工程（或公司基础设施）
   否 → 下一问

3. 它是不是“研究/实验/软件/证据/审批/预算/报告”？
   是 → 本工程
   否 → 下一问

4. 它是不是“DSH 核心、Super-agent，或通用编码代理运行时”？
   是 → 上游或对方工程
   否 → 双方评审后决定
```

## 7. 绝不能出现的重复

| 重复项 | 后果 | 预防 |
|---|---|---|
| 两套云 SDK 封装 | 状态与计费不一致 | 只在对方实现 |
| 两套 HPC 客户端 | 队列语义冲突 | 只在对方实现 |
| 两套模型网关 | 成本与路由冲突 | 只在对方实现 |
| 两套用户/租户 | 权限漏洞 | 只用对方身份 |
| 两套密钥库 | 轮换与撤销混乱 | 只用对方凭据代理 |
| 两套对象存储前缀 | 产物分裂 | 只用对方存储 |
| 两套错误码 | 无法联调 | 统一契约 |
| 两套幂等键 | 重复执行 | 统一规则 |
| 两套实验 schema | 无法合并 | 本工程唯一 |
| 两套计费口径 | 财务对不上 | 本工程统一 |
| 两套编码路由器 | 工单与会话分裂 | 只用上游 Super-agent；降级时单工单 headless，不自研 |

## 8. 若对方缺少某项能力

处理顺序：

1. 由对方补齐（首选）。
2. 对方提供临时接口，本工程只调用，不实现内部。
3. 本工程用桩实现，标记 `degraded`，禁止用于生产。
4. 若长期无法提供，双方评审是否调整边界。

禁止：本工程悄悄实现一份，之后再“合并”。
