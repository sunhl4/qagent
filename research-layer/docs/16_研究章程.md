# 研究章程（阶段 0）

本文件是 `docs/08_实施路线图与验收指标.md` 阶段 0 的交付物：把全部研究收敛到一个问题、一个基线、一个指标、一份预算、一份停止与回滚约定。平台所有自动化实验必须以本章程为边界；修改章程属于边界变更，需要按 `AGENTS.md` 的变更记录要求同步文档。

## 1. 研究问题

在数据子集漂移的训练任务上，**加入预热（warmup）调度是否能把验证损失降低至少 2%，同时训练时间退化不超过 10%**。

该问题必须是唯一问题；新的研究方向需要先修订本章程，不允许同一个平台同时跑多个章程。

## 2. 基线

| 字段 | 值 |
|---|---|
| 基线名称 | 无预热基线 |
| 来源 | 内部复现（`run REP-BASE`，环境与数据集哈希必须先登记） |
| 复现状态 | 已复现（桩环境口径） |
| 指标值 | `val_loss = 1.0`（不确定度 0.01） |

规则：基线未复现、或没有指标值时，`compileExperiment()` 会直接拒绝任何实验（`E_BASELINE_NOT_REPRODUCED` / `E_BASELINE_METRIC`）。仓库内演示口径用桩数据；接入真实资源后，此处的哈希、时间戳与复现命令必须替换为真实记录。

## 3. 主指标与方向

| 字段 | 值 |
|---|---|
| 主指标 | `val_loss` |
| 方向 | minimize |
| 最小可观测效应 | `0.02`（2%） |

决策规则由决策引擎给出：`主指标改善 ≥ 0.02 且护栏不退化且成本在预算内 → keep，否则 discard / stop / extend / escalate`，细节参见 `packages/domain/src/decision.ts` 的优先级表。

## 4. 护栏指标

| 护栏 | 阈值（相对基线退化） |
|---|---|
| `train_time_seconds` | ≤ 10% |

护栏退化超过阈值即 `discard`，无论主指标多好。

## 5. 统计要求

- 每个正式结论至少 3 个种子重复。
- 报告均值与不确定度；不只报告最好一次。
- 多种子结果不一致（相对标准差 > 0.5）→ `extend`，追加实验。

## 6. 预算

| 预算项 | 上限 |
|---|---|
| 单实验 | ≤ 5 CNY |
| 探索期总预算 | 100 CNY |
| 币种 | CNY |

配额之外：HPC、多卡、QPU、真实写入云上生产环境均需人工审批（`packages/domain/src/policy.ts`；QPU 与不可逆动作一律 `REQUIRE_APPROVAL`）。预算账本按三段法入账：准入预留 → 执行实际 → 完成释放未用部分（`packages/domain/src/cost.ts`）。

## 7. 环境与数据锁定

- 代码：实验分支 + 基线 commit（`packages/workspace/src/worktree.ts` 管理 attempt 隔离）。
- 环境：容器 digest + lockfile 哈希写入运行清单。
- 数据：`dataset_ref` + 数据集哈希 + 划分说明。
- 种子：所有种子写进 ExperimentSpec；缺失会在编译时告警。

## 8. 停止条件

| 条件 | 动作 |
|---|---|
| 单轮失败且连续失败达到 `max_consecutive_failures` | 停止循环 |
| 连续 N 轮没有保留结果（`earlyStopAfterDiscards`） | 停止循环 |
| 剩余预算为 0 或低于单轮上限 | 停止循环 |
| 到达截止时间 | 停止循环 |
| 执行状态未知 | 立即停下，人工对账，禁止重试 |
| 恢复次数达到上限 | 转人工 |

这些上限在 `ExperimentSpec.stopping` 中声明，由 `runExperimentLoop()` 执行；任一触发即停，不允许“再试一次”。

## 9. 审批与人工接口

- 预算超限、QPU/生产写入/不可逆动作必须走服务端审批。
- 需要人工判断的事件（执行未知、验证不足、恢复上限）会写入日报与循环摘要的“需要人工决策”。
- 审批决定（`PolicyContext.approvedActions`）只影响一次提交，不持久授权。

## 10. DSH 版本锁定（待公司确认）

正式接入前必须完成（当前未锁定）：

- 确认 DSH 仓库 commit 或发行版。
- 运行公司内部 conformance suite（`contracts/conformance/`）。
- 建立 adapter 替换清单（`ArtifactStore → Identity/Secrets → ModelGateway → Compute`）。

详见 `docs/11_待确认问题清单.md` 与 `docs/12_双轨开发与合并策略.md`。在锁定之前，所有执行只能在桩环境进行，产出不得称为科学结论。
