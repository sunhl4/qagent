# 公开来源登记

## 0. 说明

本文件登记本次调研使用的公开来源。等级定义：

- A：官方文档、官方仓库、官方 API、可下载代码。
- B：同行评审论文、可复现实验、生产系统报告。
- C：企业自述、媒体报道、社区文章。
- D：由 A/B 推导的工程判断。
- U：检索后无一手来源。

## 9. 检索说明

- 使用 GitHub REST API 采集部分仓库元数据，后半段触发速率限制，因此星标等数据不作为唯一依据。
- 项目能力以官方 README、文档和直接链接为准。
- 部分仓库发生过迁移（如 dvc → treeverse/dvc，pytest 相关生态、mitiq → unitaryfoundation/mitiq），本文件尽量使用当前地址。
- 未核验的功能不写入生产设计。

## 10. 未解决来源问题

以下问题在公开材料中仍不充分，需要公司内部或采购渠道确认：

- DSH 各版本的精确事件名与工具前置钩子粒度。
- DSH 插件市场的安全审查流程。
- BeamSearchDecoder（ionq-publications）的许可证是否允许公司使用与分发。确认前 qLDPC 束搜索译码只作候选。
- DSH headless 与 SDK 的稳定性承诺。
- Super-agent 可锁定版本、Ticket 接口、Watchdog 权限与端侧凭据模型。在此之前不写入长期契约。
- DeepSeek 各模型的商用条款差异。
- DeepInfer 在生产规模下的完整性能数据。
- 各云厂商与 HPC 中心的具体调度 API 与配额。
- 量子硬件供应商的作业语义、取消语义和计费规则。
