# 威胁模型

## 1. 资产

| 资产 | 说明 |
|---|---|
| 模型权重与 API 密钥 | 自部署权重、供应商密钥 |
| 用户数据 | 文献、实验数据、代码、未发表结果 |
| 计算资源 | GPU、HPC、云账号、量子设备时间 |
| 平台凭据 | 服务身份、数据库、对象存储 |
| 实验结果 | 原始数据、指标、结论、报告 |
| 代码与镜像 | 源码、依赖、容器 |
| 审计日志 | 操作与决策记录 |

## 2. 信任边界

```text
不可信
  用户输入 / 外部网页 / 论文 PDF / 模型输出 / 第三方代码 / 社区插件
        │
        ▼
半可信
  DSH 会话 / Agent 工具调用 / 沙箱内进程
        │
        ▼
可信
  平台控制面 / 策略引擎 / 凭据代理 / 资源调度器 / 审计
        │
        ▼
高可信
  硬件控制 / 校准 / 固件 / 安全互锁
```

## 3. 威胁与缓解

### 3.1 提示注入

| 项 | 内容 |
|---|---|
| 场景 | 论文、网页、代码注释中包含恶意指令 |
| 影响 | Agent 泄露数据、执行危险工具 |
| 缓解 | 输入标记为不可信；工具白名单；高风险工具走网关；输出校验；不把网页内容当系统指令 |

### 3.2 工具滥用

| 项 | 内容 |
|---|---|
| 场景 | Agent 被诱导调用 shell、网络、删除、外发 |
| 影响 | 数据泄露、资源滥用、破坏 |
| 缓解 | 工具最小化；沙箱；出网白名单；预算；审批；审计 |

### 3.3 沙箱逃逸

| 项 | 内容 |
|---|---|
| 场景 | 恶意代码利用内核或容器漏洞 |
| 影响 | 宿主被控、横向移动 |
| 缓解 | 非特权容器、gVisor/Kata、只读根、无宿主 socket、独立节点、定期补丁 |

### 3.4 凭据泄露

| 项 | 内容 |
|---|---|
| 场景 | 密钥写入代码、日志、提示、镜像 |
| 影响 | 资源被盗用、数据泄露 |
| 缓解 | 短期 token、凭据代理、扫描、最小权限、轮换 |

### 3.5 端侧 daemon 被云端循环控制

| 项 | 内容 |
|---|---|
| 场景 | 开源 Super-agent 的云端循环接入个人机器或开发机，提示注入后驱动 daemon |
| 影响 | 端侧代码、凭据和内网被使用 |
| 缓解 | daemon 不持有长期密钥；凭据走短期令牌；高风险动作走策略网关；生产不用操作系统用户免审批；不可信 Trigger 正文不当作系统指令 |

### 3.6 越权访问

| 项 | 内容 |
|---|---|
| 场景 | Agent 或用户访问其他租户数据 |
| 影响 | 数据泄露 |
| 缓解 | 硬隔离、ABAC、每租户密钥、审计、渗透测试 |

### 3.7 资源滥用

| 项 | 内容 |
|---|---|
| 场景 | 无限循环、超预算、挖矿、长期占用 |
| 影响 | 成本失控、影响他人 |
| 缓解 | 预算、配额、租约、超时、自动回收、异常检测 |

### 3.8 供应链投毒

| 项 | 内容 |
|---|---|
| 场景 | 恶意依赖、插件、镜像 |
| 影响 | 任意代码执行、数据泄露 |
| 缓解 | 锁定 digest、签名、SBOM、扫描、插件审查、最小权限 |

### 3.9 模型输出风险

| 项 | 内容 |
|---|---|
| 场景 | 幻觉、错误代码、伪造引用、有害内容 |
| 影响 | 错误结论、安全事件 |
| 缓解 | schema 校验、事实校验、引用验证、人工门、评测 |

### 3.10 数据外泄

| 项 | 内容 |
|---|---|
| 场景 | 敏感数据发给外部模型 |
| 影响 | 合规与商业损失 |
| 缓解 | 数据分类、路由约束、本地模型、出网审计、DLP |

### 3.11 执行不确定性

| 项 | 内容 |
|---|---|
| 场景 | 提交成功但结果未知，重复执行 |
| 影响 | 重复计费、实验污染 |
| 缓解 | submission token、attempt 记录、对账、禁止盲重试 |

### 3.12 插件风险

| 项 | 内容 |
|---|---|
| 场景 | 插件注册不注销、越权、后门 |
| 影响 | 资源泄漏、权限提升 |
| 缓解 | manifest 权限声明、代码审查、生命周期测试、沙箱、签名 |

### 3.13 审计缺失

| 项 | 内容 |
|---|---|
| 场景 | 无法追溯谁做了什么 |
| 影响 | 事故无法定位、合规失败 |
| 缓解 | 全链路 trace、追加写审计、哈希链、保留策略 |

## 4. 攻击路径示例

### 4.1 通过论文注入

```text
恶意 PDF 含隐藏指令
→ 解析器提取为文本
→ 模型把指令当任务
→ 调用外发工具
→ 数据泄露
```

缓解：

- 解析结果标记来源与不可信等级。
- 外发工具必须审批。
- 模型不直接拥有外发工具。
- DLP 检查。

### 4.2 通过依赖投毒

```text
Agent 安装恶意包
→ 包在安装时执行脚本
→ 读取环境变量中的 token
→ 外传
```

缓解：

- 禁止生命周期脚本。
- 锁定依赖与哈希。
- 无长期 token 在环境。
- 出网白名单。
- 安装前扫描。

### 4.3 通过插件后门

```text
安装社区插件
→ 插件注册隐藏工具
→ 模型被诱导调用
→ 越权访问
```

缓解：

- 插件白名单。
- 权限声明与审查。
- 运行时权限校验。
- 签名与来源验证。

## 5. 安全测试

| 测试 | 频率 |
|---|---|
| 沙箱逃逸 | 每季度 |
| 提示注入 | 每次模型/提示变更 |
| 越权 | 每季度 |
| 密钥扫描 | 每次提交 |
| 依赖扫描 | 每日 |
| 渗透测试 | 每半年 |
| 事故演练 | 每季度 |

## 6. 残余风险

即使完成上述缓解，仍存在：

- 模型不可预测行为。
- 零日漏洞。
- 内部人员滥用。
- 供应链上游被攻陷。
- 合规环境变化。

因此必须保留：

- 人工审批门。
- 快速撤销能力。
- 备份与恢复。
- 事故响应流程。
