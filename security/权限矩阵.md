# 权限矩阵

## 1. 角色

| 角色 | 说明 |
|---|---|
| Viewer | 只读 |
| Researcher | 发起研究任务、读文献、跑预算内实验 |
| Engineer | 修改代码、跑测试、提 PR |
| Operator | 管理资源与队列，不含安全策略 |
| SecurityAdmin | 策略、审批、审计 |
| PlatformAdmin | 平台配置与租户管理 |
| Agent | 自动化主体，权限由任务授予 |

## 3. Agent 权限

Agent 不继承操作者全部权限。任务创建时授予：

```yaml
agent_grant:
  task_id: "..."
  scopes:
    - "literature:read"
    - "workspace:write"
    - "test:run"
    - "experiment:submit:budget<=20CNY"
  denied:
    - "network:internet"
    - "secrets:cloud"
    - "git:push:main"
    - "resource:qpu"
  expires_at: "..."
  max_cost: 20.0
  currency: CNY
```

规则：

- 默认拒绝。
- 按任务授予。
- 到期自动失效。
- 不可转授。
- 高风险动作必须单独审批。

## 4. 租户隔离

| 资源 | 隔离 |
|---|---|
| 工作区 | 每任务独立 |
| 对象存储 | 每租户前缀 + 密钥 |
| 数据库 | schema 或实例隔离 |
| 计算节点 | 高敏租户专属 |
| 模型端点 | 按租户配额 |
| 审计 | 按租户视图 |
| 缓存 | 按安全域分区 |

## 5. 审批规则

```text
if action.risk == critical:
    require two approvers from security
elif action.risk == high:
    require one approver from owner team
elif action.cost > budget * 0.5:
    require budget owner approval
elif action.irreversible:
    require explicit confirmation
else:
    allow
```
