# 安全检查清单

## 1. 开发环境

- [ ] 依赖锁定并校验哈希
- [ ] 不使用安装期生命周期脚本
- [ ] 密钥不写入仓库
- [ ] 提交前密钥扫描
- [ ] 代码静态扫描
- [ ] 依赖漏洞扫描

## 2. 沙箱

- [ ] 非特权运行
- [ ] 只读根文件系统
- [ ] 无宿主 socket
- [ ] 无云元数据访问
- [ ] 默认拒绝出网
- [ ] 出网白名单
- [ ] CPU/内存/进程/磁盘限制
- [ ] 硬超时
- [ ] 独立工作区
- [ ] 任务结束销毁

## 3. 凭据

- [ ] 无长期密钥进入沙箱
- [ ] 短期 token
- [ ] token 绑定租户/项目/资源/动作
- [ ] 通过 socket 或受限文件注入
- [ ] 任务结束撤销
- [ ] 定期轮换
- [ ] 泄露演练

## 4. 工具

- [ ] 每个工具有明确副作用声明
- [ ] 高风险工具不直接暴露
- [ ] 工具参数校验
- [ ] 输出结构化
- [ ] 超时
- [ ] 幂等或显式非幂等
- [ ] 调用审计

## 5. 策略

- [ ] 默认拒绝
- [ ] 身份与租户检查
- [ ] 配额与预算检查
- [ ] 数据地域检查
- [ ] 风险等级检查
- [ ] 审批状态检查
- [ ] 失败关闭（fail closed）
- [ ] 决策可解释
- [ ] 决策审计

## 6. 插件

- [ ] manifest 完整

- [ ] 版本兼容声明
- [ ] 健康检查
- [ ] 生命周期测试

- [ ] 签名与来源
- [ ] 升级回滚方案
